# 爪印花园 · PetMemorial

独立 iOS 首版项目。SwiftUI + RealityKit，最低 iOS 17，支持 iPhone / iPad。
临时显示名称：爪印花园。Bundle ID：cn.cjym.petmemorial。版本：1.0.0 (1)。

## 打开与运行

用 Xcode 打开 `PetMemorial.xcodeproj`，选择 `PetMemorial` scheme 和设备运行。
签名团队沿用开发者现有配置，首次在其他机器运行时需选择自己的开发团队。
无 CocoaPods、无第三方 SDK、无第三方模型包依赖。

## 已实现

- 手机验证码 / 密码登录，复用现有 App 用户库；支持验证码重设密码。登录令牌保存于 Keychain，不保存密码。
- 首次登录可关联游客资料和碑位；账号已有纪念园时不覆盖，游客与各账号本机文件隔离。退出不删除账号资料。
- 绑定后按后台 user ID 识别碑位，已绑定的匿名钥匙不能再绕过账号读取资料。
- 账号可恢复云备份；未开启云备份的私密资料仍仅保存在本机。
- 创建 / 编辑一个私人纪念花园：名字、猫或狗、生日、告别日期、故事。
- 原创程序化 3D 场景：树、长椅、步石、照片相框、小动物、花和灯。
- 单指绕场景旋转、双指缩放、轻触伙伴跳动反馈。
- 首页私人花园预览；全屏共享纪念园：48 座纪念碑、摇杆第三人称行走、跟随镜头、碰撞边界、地图定位。
- 共享碑位认领 / 迁移 / 释放，每个钥匙身份限一座；服务端唯一约束阻止重复占位。
- 经用户确认仅公开宠物昵称、首张照片缩略图、纪念介绍；信件和其他照片保持私密。
- 顶部园区菜单支持刷新碑位、晴日 / 黄昏 / 月夜。
- 最多 6 张照片，系统照片选择器，端侧下采样压缩，第一张显示在花园相框。
- 写信、阅读、删除，最多 100 封，每封 2000 字。
- 献花与点灯计数，场景最多绘制 12 束花 / 5 盏灯以控制负载。
- 本机原子文件保存；重新打开应用保留资料。
- 明确同意后启用私密云备份，编辑后自动同步，启动时补做备份。
- 备份钥匙保存在 Keychain，可自行导出，用钥匙跨设备恢复。
- 删除全部资料：云端成功删除后才清空本机；失败保留原数据。

## 数据与边界

默认不上传私密资料；进入共享园区获取公开碑位列表，认领需要确认发布。
共享的是纪念碑数据，人物行走在本机渲染，尚未实现其他在线用户的实时人物同步、聊天、广告、AI 对话或付费。
照片用 JPEG 副本备份，不修改系统相册原图。单张 JPEG 最大 145 KB；总备份最大 1.6 MB。
备份访问使用 256-bit 随机钥匙，服务端仅保存其 SHA-256 索引；所有网络传输使用 HTTPS。
未绑定的游客备份是持有钥匙即有访问权；绑定后必须使用后台账号令牌访问。两种方式均不是端到端加密。
账号登录复用 /im/bot/login-code、login-by-code、login-by-password、set-password。没有改动这些原接口或其他 App 的业务逻辑。
新增 /api/petmemorial/account/bind 和 pet_memorial_account，将稳定的后台用户 ID 映射到原纪念园所有者，不迁移或公开信件。
云端版本冲突不会覆盖他处记录，需要先在“我的”恢复云端版本。
云端服务暂不可用不影响本机阅读与创作。

当前是功能验证首版，不代表已经具备公开上架的全部材料。正式上架前需补齐运营主体、隐私联系渠道、数据保留和运维备份清理策略、APP 备案、商店隐私申报及真机体验验证。

## 后台

服务端代码：`/Users/liuzheng/clawboootdo/src/main/java/com/bootdo/petmemorial/PetMemorialController.java`。
独立路径 `/api/petmemorial/*`；私密表 `pet_memorial_garden`，公开碑位表 `pet_memorial_plot`。
`ParkController.java` 提供 `/api/petmemorial/park` GET / PUT / DELETE。读取只返回公开白名单和当前身份是否持有。
每次进入或手动刷新获取最新占位，认领提交时再次由数据库仲裁；不是实时联机广播。
公开内容通过碑位详情主动更新；修改私人资料不会自动公开。删除全部资料先释放公开碑位，再删除备份和本机资料。
写操作使用连接内新建并关闭的 PreparedStatement，避开现有 Druid 缓存冲突后复用已关闭语句的问题，不修改全局连接池。
不读取、不改动原有 AI / 会员 / 睡眠业务表。部署细节见 `docs/DEPLOYMENT.md`。

## 爪印小镇（2026-11-23）

在花园首页选择“走进爪印小镇”。原有 48 座共享纪念碑编号及服务端接口保持不变。
新增入口广场、记忆小屋、时光邮局、陪伴草地；点击建筑或走近入口可打开功能页，右上角地图支持传送和原碑位检索。

建筑外景为 RealityKit 程序化几何体；建筑内部目前使用 SwiftUI 功能页面，不是可行走的室内 3D 场景。不新增模型 API 或服务器接口。
